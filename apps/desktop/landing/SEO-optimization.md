## 1. МЕТА-ТЕГИ

### 1.1 Title (50–60 символів)
```html
<title>LUMEN AI — Впровадження ШІ для бізнесу | Стратегія, автоматизація, продукти</title>
```

**Пояснення:** Поточний title "ШІ, що працює на ваш бізнес" (38 симв.) — надто короткий, не містить ключових слів. Новий title включає основний бренд + ключові напрямки (стратегія, автоматизація, продукти) та цільову аудиторію (бізнес). Формула: `[Бренд] — [ціннісна пропозиція] | [ключові послуги]`.

### 1.2 Meta Description (150–160 символів)
```html
<meta name="description" content="LUMEN AI: від стратегії до запуску ШІ-рішень. Скорочуємо операційні витрати до 42%, повертаємо 160+ год/міс команді. Кейси, діагностика, впровадження за 9 тижнів.">
```

**Пояснення:** Поточний опис (138 симв.) — абстрактний. Новий містить конкретні цифри (соціальний доказ), перелік ключових сторінок (кейси, діагностика, впровадження), часовий орієнтир (9 тижнів). Цифри підвищують CTR у SERP на 15–30%.

## 5. ТЕХНІЧНІ SEO-РЕКОМЕНДАЦІЇ

| Параметр | Поточний стан | Рекомендація |
|----------|--------------|--------------|
| **h1** | 1 (ок) | ✅ |
| **h2** | 5 (ок) | Додати keywords у h2 |
| **Зображення** | Немає alt-ів для декоративних елементів | Додати описові alt, де потрібно |
| **Canonical** | Відсутній | Додати self-referencing canonical |
| **Hreflang** | Відсутній | Додати, якщо буде мультимовна версія |
| **Sitemap** | Відсутній | Створити sitemap.xml |
| **robots.txt** | Відсутній | Створити robots.txt |
| **Структуровані дані** | Відсутні | Додати Organization + FAQPage + Service |
| **Core Web Vitals** | Чистий HTML/CSS — має бути добре | Перевірити LCP, CLS після деплою |
| **Мобільна версія** | Є media queries | ✅ |
