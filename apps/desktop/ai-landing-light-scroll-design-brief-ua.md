## 4. Стилі скрол-анімацій

### Базовий fade-up
```css
.reveal {
  opacity: 0;
  transform: translateY(24px);
  transition: opacity 0.6s cubic-bezier(0.22, 1, 0.36, 1),
              transform 0.6s cubic-bezier(0.22, 1, 0.36, 1);
  transition-delay: var(--delay, 0ms);
  will-change: opacity, transform;
}
.reveal.is-visible {
  opacity: 1;
  transform: translateY(0);
}
```
- **Тригер:** IntersectionObserver, `threshold: 0.15`, анімація спрацьовує один раз (unobserve після появи).
- **Fade-in (без руху)** для фонових блоків: тільки `opacity 0 → 1`, 800ms.

### Stagger-затримки (через CSS-змінну `--delay`)
| Секція | Елементи | Затримки |
|---|---|---|
| Hero (при завантаженні) | бейдж, H1, підзаголовок, CTA, візуал, статистика | 0 / 80 / 160 / 240 / 320 / 400 ms |
| Features (6 карток) | картка 1..6 | 0 / 100 / 200 / 300 / 400 / 500 ms |
| How It Works (3 кроки) | крок 1..3 | 0 / 150 / 300 ms |
| Pricing (3 тарифи) | картка 1..3 | 0 / 150 / 300 ms (Pro — виділений, але порядок той самий) |
| Testimonials (3 відгуки) | картка 1..3 | 0 / 150 / 300 ms |
| CTA-блок | блок цілком | 0 (fade-up блоку) |

- Заголовки секцій (H2 + підзаголовок) з'являються раніше за сітку: заголовок 0ms, підзаголовок 100ms, потім картки.

### Hover-ефекти
- **Картки (features/testimonials/pricing):** `transform: translateY(-4px)`; тінь `shadow-sm` → `shadow-md`; `transition: all 0.3s ease`; курсор не змінюється (крім клікабельних).
- **Іконки в картках:** `transform: scale(1.1)`; підкладка `#EEF2FF` → `#E0E7FF` (transition 0.3s).
- **Primary-кнопки:** bg `#6366F1` → `#4F46E5`; `translateY(-1px)`; тінь `0 8px 24px rgba(99,102,241,0.25)`; transition 0.2s.
- **Secondary-кнопки:** bg `#FFFFFF` → `#F8FAFC`; рамка `#E2E8F0` → `#CBD5E1`.
- **Посилання navbar:** колір → `#6366F1`, підкреслення 2px з offset 6px.
- **Фокус:** всі інтерактивні елементи мають `outline: 2px solid #6366F1; outline-offset: 2px` на `:focus-visible`.
- **CTA-кнопка на градієнті:** bg біла → `#EEF2FF`.

### Доступність руху
```css
@media (prefers-reduced-motion: reduce) {
  .reveal { opacity: 1; transform: none; transition: none; }
  * { scroll-behavior: auto !important; }
}
```
- При `prefers-reduced-motion: reduce` усі елементи видимі одразу, без трансформацій.

- **Формат:** inline SVG (stroke-based), `stroke-width: 1.5–2`, `stroke: currentColor` (колір наслідує контекст).

- **Колір:** `#6366F1` на підкладці `#EEF2FF`; check — `#10B981`; зірки — `#F59E0B`; футер — `#94A3B8` (hover `#FFFFFF`).
- **Доступність:** декоративні SVG — `aria-hidden="true"`; значущі — `role="img"` + `aria-label`.
- **Emoji** дозволені для: декоративних бейджів (✨, 🚀, 🤖, ⚡), аватарів у відгуках. У інтерфейсі — лише SVG.
- **Набір SVG для фіч:** zap (⚡ автоматизація), file-text (генерація контенту), bar-chart (аналітика), shield (безпека), puzzle/plug (інтеграції), headset (підтримка 24/7).

## 6. Технічні вимоги до реалізації (чек-лист)

1. Один `<link>` на Google Fonts (Unbounded + Inter з кирилицею — `display=swap`).
2. Усі кольори, радіуси, тіні, відступи — CSS custom properties (токени з розділу 1–5).
3. Mobile-first, брейкпоінти: 640px (sm), 768px (md), 1024px (lg).
4. Скрол-анімації — IntersectionObserver з `once: true`; класи `.reveal` + `--delay`.
5. Обов'язково `@media (prefers-reduced-motion: reduce)`.
6. Семантична розмітка: `<nav>`, `<main>`, `<section>` (з `aria-labelledby`), `<footer>`; один `<h1>`.
7. `scroll-behavior: smooth` на html; якірні посилання з `scroll-margin-top: 88px` (врахувати sticky navbar).
8. Зображення — `loading="lazy"` (крім hero), `width/height` задані, щоб уникнути CLS.
9. Плавне з'явлення hero — через клас на `<body>`/`<main>` після завантаження (CSS keyframes з `animation-delay`), а не через скрол.
10. Перевірка контрасту: текст на білому ≥ 4.5:1 (задовольняють усі токени тексту з розділу 1).
